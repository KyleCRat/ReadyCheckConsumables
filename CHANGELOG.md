# Changelog

## [Unreleased]

### Changed

- The Consumables Action Bar now defaults to Medium frame strata, matching
  Blizzard's action bars. A Frame Strata setting lets you adjust its layering.

## [12.1.5-29] - 2026-10-13

### Added

- Update highlights with settings you can change directly, a full changelog in
  Settings, and an account-wide option to turn future update popups off. Use
  `/changelog` to browse the latest notes from all participating addons.
- Added optional Invisibility Potion buttons to both personal displays, with
  preferred items, counts, and cooldowns. Supports all ranks of Hushed Zephyr,
  Silent Footfalls, and Void-Shrouded Tincture. Existing Tincture preferences
  move from Combat Potion to the new button.
- Added optional Glide buttons to both personal displays for Goblin Glider Kits
  and collected parasol toys, with preferred choices and cooldowns. Off by default.
- Chat Report settings now let you choose individual report types for automatic
  and manual reports, and toggle the bench-aware Everyone Ready announcement.

### Changed

- Consumables Frame buttons now use only the four open-event choices, without
  a separate Enabled column. Previously disabled buttons remain unchecked, and
  update highlights offer the same event choices.

## [12.1.5-28] - 2026-10-06

- Updated for WoW 12.1.5.

### Fixed

- Raid Buff buttons now show a red X for confirmed missing buffs even when
  another group member cannot be checked.
