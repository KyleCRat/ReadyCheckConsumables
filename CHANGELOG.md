# Changelog

## [Unreleased]

### Added

- Added optional Invisibility Potion buttons to both personal displays, with
  preferred items, counts, and cooldowns. Supports all ranks of Hushed Zephyr,
  Silent Footfalls, and Void-Shrouded Tincture. Existing Tincture preferences
  move from Combat Potion to the new button.
- Added optional Glide buttons to both personal displays for Goblin Glider Kits
  and collected parasol toys, with preferred choices and cooldowns. Off by default.

## [12.1.5-28] - 2026-10-06

- Updated for WoW 12.1.5.

### Fixed

- Raid Buff buttons now show a red X for confirmed missing buffs even when
  another group member cannot be checked.

## [12.1.0-27] - 2026-09-21

### Fixed

- Vantus Rune buttons and macros now support The Tidebound Grotto, and personal
  and raid displays recognize Nymrissa Wavecaller's active rune.
